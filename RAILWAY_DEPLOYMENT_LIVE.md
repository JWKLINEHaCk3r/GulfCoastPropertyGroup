## 🎯 Quick Start (5 Minutes)

### 1. **Go to Railway.app**
```
https://railway.app
```

### 2. **Connect Your GitHub Repository**
- Click "Create Project"
- Select "Deploy from GitHub"
- Authorize GitHub
- Choose `GulfCoastPropertyGroup` repository
- Click "Deploy"

### 3. **Set Environment Variables**

Railway will automatically detect the `start.sh` file. Add these variables in Railway project settings:

```
# Database (Railway provides PostgreSQL)
# Railway auto-generates DATABASE_URL, so you can reference it directly
DATABASE_URL=postgresql://...          # (Railway auto-generates)
REDIS_URL=redis://...                  # (Railway auto-generates)

# API Keys
OPENAI_API_KEY=sk-...
ANTHROPIC_API_KEY=claude-...
STRIPE_SECRET_KEY=sk_live_...

# Environment
ENVIRONMENT=production
DEBUG=false

# Server
PORT=8000
WORKERS=4

# App Secrets
SECRET_KEY=your-super-secret-key-here-min-32-chars
```

### 4. **Add PostgreSQL and Redis Services** (Optional but Recommended)
- Click "Add Services" in Railway
- Select "PostgreSQL" → Add
- Select "Redis" → Add
- Railway automatically sets DATABASE_URL and REDIS_URL

### 5. **Deploy**
- Click "Deploy" 
- Wait 3-5 minutes for build completion
- Check "Deployments" tab for logs

## 🔍 How It Works

### What `start.sh` Does:
1. **Builds Frontend**
   - Installs npm dependencies
   - Runs `npm run build` (Vite production build)
   - Outputs to `frontend/dist/`

2. **Prepares Backend**
   - Copies frontend dist to `backend/static/`
   - Installs Python dependencies
   - Runs database migrations (if needed)

3. **Starts Application**
   - Launches FastAPI with Uvicorn
   - Serves API on `/api/*` routes
   - Serves frontend from root `/`

### Application Flow:
```
User Request (https://yourapp.railway.app)
    ↓
Uvicorn (Python, Port 8000)
    ├→ /api/v1/* → FastAPI Routes (backend logic)
    ├→ /docs → Swagger API Documentation
    └→ /* → Static Frontend (Vue app)
```

## 📈 Scaling

### Increase Worker Threads:
Edit `railway.json`:
```json
{
  "deploy": {
    "startCommand": "bash start.sh",
    "restartPolicyType": "on_failure"
  }
}
```

Then set environment variables:
```

ENVIRONMENT=production
```

## 🐛 Troubleshooting

### Error: "Script start.sh not found"
✅ Fixed! We created `start.sh` at the root with proper permissions

### Error: "npm: command not found"
- Railway detected Python but not Node
- Check `railway.json` is present
- Try rebuilding with "Rebuild" button in Railway

### Error: "ModuleNotFoundError"
- Something in Python imports failed
- Check logs for which module is missing
- Add to `backend/requirements.txt`

### Error: "Database connection refused"
- PostgreSQL service not initialized
- Add PostgreSQL service in Railway dashboard
- Wait 2-3 minutes for initialization
- Restart deployment

### Slow Build (>10 minutes)
- First builds are slow (downloads all dependencies)
- Subsequent deploys are faster (cached layers)
- Consider upgrading to Railway Pro for faster builds
